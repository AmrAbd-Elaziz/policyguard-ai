# PolicyGuard AI

Firewall security policy analysis, contextual risk prioritization, remediation guidance, and security control mapping.

Supported inputs:

- Normalized CSV / JSON
- Palo Alto-style CSV
- FortiGate firewall policy configuration

PolicyGuard uses deterministic detection and risk logic. No external AI model is required for firewall analysis.
